# 📖 About

This directory contains my **Hack The Box** write-ups completed during my cybersecurity learning journey.

The purpose of these write-ups is to document my progress, reinforce newly learned concepts, and build a structured knowledge base for future reference.

Each write-up focuses on the methodology, security concepts, and lessons learned from the machine rather than simply recording the final result.

---

# 🎯 Objectives

- Document solved Hack The Box machines.
- Improve enumeration methodology.
- Practice documentation skills.
- Build a personal cybersecurity knowledge base.
- Review common security misconfigurations.
- Reinforce defensive security concepts.
