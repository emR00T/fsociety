# 📖 About

**fsociety Git Manager** is a lightweight graphical interface built with **Python** and **Tkinter** to simplify common Git operations.

Instead of repeatedly typing Git commands in the terminal, this application provides a clean desktop interface for staging files, checking repository status, creating commits, and pushing changes.

It is designed for developers who want a simple and efficient Git workflow.

---

# ✨ Features

- 🖥️ Modern GitHub-inspired dark interface
- 📦 Stage all files (`git add .`)
- 📋 View repository status
- 💬 Custom commit messages
- ✅ One-click commits
- 🚀 Push changes to remote repository
- 📤 Live command output
- 📍 Status indicator
- ⚡ Lightweight and responsive
- 🐍 Pure Python implementation

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/emR00T/fsociety.git
```

Move into the project directory:

```bash
cd fsociety/tools
```

Run the application:

```bash
python gitgui.py
```

# 🎯 Supported Git Commands

| Command | Description |
|----------|-------------|
| git add . | Stage all modified files |
| git status | Show repository status |
| git commit | Create a commit with a custom message |
| git push | Push commits to the remote repository |
